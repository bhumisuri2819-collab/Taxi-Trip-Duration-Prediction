**NYC Taxi Trip Duration Prediction**

This project focuses on predicting New York City taxi trip durations using real-world transportation data from the Kaggle NYC Taxi Trip Duration dataset. The objective was to build a machine learning pipeline capable of estimating trip duration based on temporal and geographical trip features.
The project includes data cleaning, exploratory data analysis (EDA), feature engineering, and regression model training using Python and Scikit-learn. Various trip-related patterns such as peak travel hours, passenger trends, and location-based insights were analyzed to improve prediction accuracy.

**Key Highlights**
* Performed data preprocessing and handled missing/outlier values
* Conducted EDA to identify travel and traffic patterns
* Engineered time-based and location-based features
* Trained and evaluated regression models using RMSE and R² metrics
* Built an end-to-end machine learning workflow for predictive analytics

**Tech Stack**
* Python
* Pandas
* NumPy
* Matplotlib & Seaborn
* Scikit-learn
* Jupyter Notebook
